# ROS 2 reference evaluation checklist

- [ ] Partner, site, technical owner, safety owner, date recorded
- [ ] Isolated `ROS_DOMAIN_ID` recorded
- [ ] ROS distro, RMW, controller, device, and joint order recorded
- [ ] Independent E-Stop/protective stop verified by partner
- [ ] SROS2 `Enforce` and enclave permissions reviewed
- [ ] `rlsok ros2 doctor` output attached
- [ ] `rlsok ros2 inspect` output attached
- [ ] Six ROS 2 reference test categories pass
- [ ] 100+ Shadow proposals, zero controller goals
- [ ] Negative matrix completed
- [ ] Evidence bundle verifies
- [ ] Canary authorization recorded, if performed
- [ ] Revocation/cancel evidence compared with controller log
- [ ] Residual risks and follow-up owners recorded

Outcome: `continue engineering` / `stop` / `not evaluated`.
