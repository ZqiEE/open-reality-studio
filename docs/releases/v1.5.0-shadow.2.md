# v1.5.0-shadow.2 — reusable interface configuration

This **evaluation prerelease** adds read-only interface discovery and reusable
configuration import for the browser workflow at <https://rlsok.com/connect>.
It retains zero controller dispatch and local, self-attested approval.

- `profile discover` exports actual environment, visible endpoints and installed
  definition fingerprints. Missing definitions remain unavailable; conflicting
  graph identities/types fail collection.
- `profile inspect-connection` and `profile configure` consume saved connections,
  bind selections to catalog definitions and validate mapped example goals.
- The website and Runtime share portable profile, goal and onboarding validators.
  Users can select compatible action semantics, map renamed fields, choose real
  configuration files, download a consumable workspace and save reusable settings.
- Generated catalog/connection schemas, installation and configuration guides,
  source identity, checksums, SBOM and licenses ship with the evaluation assets.

Supported adapters: standard FollowJointTrajectory, absolute meters/quaternion
Cartesian poses, relative mm/WPR-degree Cartesian deltas and exact allowlisted
program names. Arbitrary protocols, incompatible units/semantics, custom
trajectory point layouts and active-controller exporter generation are outside
scope. Mapping does not establish physical compatibility or motion safety.

Validation: source/contract/diff review and delivery-essential TypeScript/package
build only. No local tests, full gates, GitHub Actions, ROS/Humble runs, installer
execution, private-action acceptance or physical robot validation. Website
deployment and focused layout inspection are reported separately. Customer use
and acceptance are not established by this publication.

Install into a new evaluation directory. This does not upgrade stable Runtime
v1.4.5, change Cloud/API/schema v1.3.0, update Windows, create Cloud approvals or
replace a robot execution stack. Read [the onboarding guide](../interface-onboarding.md)
and [installation guide](../fanuc-shadow-self-service.md).
